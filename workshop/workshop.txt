title=LuaBuddy [B42] - Native Mod Manager (Linux)
description=[h1]Manage your mods without guessing what loaded[/h1]
description=LuaBuddy is a Rust-native mod manager and client/shared Lua loader for Project Zomboid. Browse your installed mods, search the Workshop, choose eligible mods to load during play, and see what actually happened. It also provides a reusable JVM patch engine for mod developers.
description=
description=[b]Steam includes the native Linux setup package. One-time graphical activation is required.[/b] Subscribe, extract the included archive with your desktop archive manager, and double-click luabuddy. This flow needs no terminal command or separate download. It targets native Linux x86_64 with an existing Zenity or KDialog desktop utility. Windows, macOS, and Proton game execution are not supported by this release.
description=
description=[h2]Why use LuaBuddy?[/h2]
description=[list]
description=[*]See the difference between subscribed, installed, selected for next launch, and loaded in this session. A saved selection is not reported as a successful load.
description=[*]Add eligible client/shared Lua mods during play. Some mods still need a reconnect or normal startup, and LuaBuddy explains those limits.
description=[*]Browse installed and subscribed mods, search Workshop as you type, inspect descriptions and dependencies, and request subscriptions or downloads from the game.
description=[*]Use separate actions for this session, the next launch, Workshop delivery, and diagnostics. Built-in help covers complete workflows.
description=[*]Test your own local mods in place. Optional one-launch selections expire after that game process, including its reconnects, without deleting your source or normal profiles.
description=[*]Keep the mods you choose. A fresh installation enables no mods, and bundled integration profiles are optional.
description=[/list]
description=
description=[h2]How it works[/h2]
description=LuaBuddy installs a Rust native library through the game's launcher configuration. It uses Project Zomboid's existing JVM, Kahlua interpreter, mod discovery, dependency metadata, translations, and interface controls. Upstream Workshop mods remain in Steam's folders and run through the game's own Lua facilities.
description=
description=A profile identifies a native mod ID. Most integrations start with that ID alone. Optional declarative settings or compiled Rust hooks handle specific lifecycle needs. Repeated refresh keeps already loaded modules and callbacks intact. Reload is available only when an integration provides the required cleanup cooperation. A successful initial load does not make a mod safe to reload.
description=
description=LuaBuddy includes its own patch engine. It has no ZombieBuddy dependency and needs no Python, additional Lua interpreter, or runtime compiler on the player's machine.
description=
description=[h2]Install through graphical setup[/h2]
description=[b]Quit Project Zomboid before setup. Use the native Linux game, not Proton.[/b]
description=[olist]
description=[*]Subscribe to this item and let Steam finish downloading it.
description=[*]In your Steam Library, right-click Project Zomboid and choose [b]Manage > Browse local files[/b].
description=[*]In the file manager, move up through parent folders until you reach [b]steamapps[/b]. Then open the path below.
description=[*]Open [b]LuaBuddy-Setup-linux-x86_64.tar.gz[/b] with your desktop archive manager and extract it.
description=[*]Open the extracted [b]LuaBuddy-...[/b] folder and double-click [b]luabuddy[/b]. Keep all package files together.
description=[*]Check the game folder, choose [b]Install / update[/b], and read the result. Setup lets you choose the game folder if discovery needs help.
description=[*]Close setup, launch the game normally through Steam, and open [b]Options > Mods > LuaBuddy > Manage mods[/b].
description=[/olist]
description=Folder beneath steamapps:
description=[code]workshop/content/108600/3838682402/mods/LuaBuddy_SetupGuide/common/setup[/code]
description=The package requires Linux x86_64 and glibc 2.34 or newer. The runtime was tested on Project Zomboid 42.22.2. Graphical setup needs an existing Zenity or KDialog utility; desktops without either cannot use this flow. Setup verifies the extracted package and uses the game's bundled JVM. A fresh installation selects no mods. The guide mod itself does not need to be enabled.
description=
description=[h2]Your first mod[/h2]
description=Install the upstream mod and its required dependencies. In [b]Manage mods[/b], select [b]Installed[/b] and search for it. Inspect the mod details and choose the workflow you need.
description=[list]
description=[*][b]This session:[/b] choose [b]Enable late[/b], then [b]Load enabled[/b] for eligible client/shared content. Read the result to see whether it loaded or needs a reconnect or restart.
description=[*][b]Next launch:[/b] choose [b]Startup enable[/b] for normal game startup loading. Restart the game to apply it.
description=[*][b]Reload:[/b] use [b]Reload a profile[/b] to search installed IDs or type a custom ID with suggestions. Mods without a cleanup contract need a reconnect instead.
description=[/list]
description=Disabling a late selection changes future environments. It does not remove code already running in the current session. Apply or discard pending Options edits before changing selections.
description=
description=[h2]Optional integrations[/h2]
description=The package includes profiles for mods such as AllTheInfo, Auto All, NeatUI Inventory and Mechanics, Craft Planner, LootSense, and Easy Drop'n'Loot. These profiles do not bundle those mods or enable them automatically. Install upstream content separately and choose the integrations you want. Other mods can use generic profiles with their native mod IDs.
description=
description=[h2]Limits and multiplayer[/h2]
description=Late Lua loading cannot supply missing server code, bypass server policy or checksums, register every map/item/animation asset, or reconstruct the entire startup lifecycle. Some content must be enabled normally on the client, server, or both. LuaBuddy does not grant permission to run native extensions just because a Workshop item was downloaded.
description=
description=This is a release candidate. The Linux native checks and exercised in-game workflows are documented in the repository. There is no established FPS improvement or completed performance-budget result. Physical-controller testing and Windows/macOS game execution remain unverified. Future game updates can change private APIs and require a LuaBuddy update.
description=
description=[h2]Updates, help, and removal[/h2]
description=Steam updates the included archive. To activate a native update, close the game, extract the newly delivered package, open its luabuddy executable, and choose [b]Install / update[/b]. Setup also provides [b]Verify installed files[/b], [b]Repair[/b], [b]Recover interrupted setup[/b], [b]Roll back[/b] when available, and [b]Remove LuaBuddy[/b]. It preserves existing profiles and settings. Native changes apply after the next normal Steam launch; setup does not control a running game. Unsubscribing alone does not uninstall an installed runtime.
